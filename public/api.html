API Documentation

Available endpoints for your ADEZ TECH services.

GET /api/services
Returns the available services. 
curl -X GET \
https://your-domain.com/api/services \
-H "X-API-Key: YOUR_API_KEY"
POST /api/order
Creates a service order. 
curl -X POST \
https://your-domain.com/api/order \
-H "Content-Type: application/json" \
-H "X-API-Key: YOUR_API_KEY" \
-d '{
  "service": "SERVICE_ID",
  "link": "https://example.com",
  "quantity": 100
}'
GET /api/order/ORDER_ID
Checks the status of an order. 
curl -X GET \
https://your-domain.com/api/order/ORDER_ID \
-H "X-API-Key: YOUR_API_KEY"
GET /api/balance
Returns the current wallet balance. 
curl -X GET \
https://your-domain.com/api/balance \
-H "X-API-Key: YOUR_API_KEY"

Example Response

A successful API response should return JSON data. 

{
  "success": true,
  "balance": 1500.00,
  "currency": "KES"
}
